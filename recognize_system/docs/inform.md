## 二、研究背景与核心思想（原理）

### 2.1 问题背景

- 在数千种已知罕见病中，约 **30%～40%** 的患者存在面部异常（面部畸形特征）。
- 因此面部特征识别可作为一种利用机器学习预测罕见病风险和类型的有效手段。
- **核心矛盾**：深度学习模型（如 Face2Gene、DCNN-ArcFace）效果好，但有两个致命短板：
  1. **依赖大量样本** —— 而罕见病图像数据极其稀缺（本文仅 109 张）；
  2. **可解释性差** —— "黑箱"特性使其内部机制不透明，无法与医学上已知的面部特征直接对应。

### 2.2 本文的解决思路

> **用人工定义的"几何特征"补充深度特征，在极小样本下提升分类性能，同时获得可解释性。**

技术路线可概括为一句话：

```
Dlib 68 关键点  →  61 个可解释几何特征（35 距离 + 26 角度）
                →  随机森林筛选 Top 10
                →  与 Dlib 128 维深度特征拼接
                →  138 维融合特征
                →  4 种机器学习模型 × 10 折交叉验证
```

### 2.3 为什么这样设计是有效的（原理层）

1. **几何特征的本质**：用关键点之间的**距离**和**角度**做比值/归一化，等价于把一张人脸投影到一个**尺度无关、位置无关的低维形状空间**。这使得仅需几十个样本即可估计出稳定的分布，而不像 CNN 那样需要上万样本去学习滤波器权重。
2. **距离特征捕捉"尺寸与比例"**：如眼距过宽/过窄、鼻梁过长/过短 —— 对应唐氏综合征（眼距宽、鼻梁扁）、Williams 综合征（鼻尖宽、嘴唇厚）等典型表型。
3. **角度特征捕捉"轮廓走向与倾斜"**：如眼角上扬/下垂、嘴角倾斜 —— 对应 DiGeorge 综合征的面部不对称等。
4. **归一化的必要性**：不同照片的拍摄距离、分辨率不同，原始像素距离无意义。用**脸部宽度**（点 0 到点 16）作分母，消除尺度差异；角度特征本身就与尺度无关，只需取绝对值消除左右方向符号。
5. **特征选择的作用**：61 个特征相对 109 个样本而言维度过高，直接建模必然过拟合。用随机森林评估重要性后取 Top 10，是典型的小样本降维策略。
6. **融合的动机**：几何特征可解释但表达力有限（只能覆盖部分表型）；深度特征表达力强但不可解释。二者**互补**，融合后既提性能又保留部分可解释性。

**距离计算实现**

- 两点距离：欧氏距离
  ```
  d(a, b) = sqrt((x_a - x_b)² + (y_a - y_b)²)
  ```
- 多点"线段长度和"（如 left_eyebrow_length）：按**给定点序**依次连接相邻点求欧氏距离后**求和**
  ```
  L = Σ d(p_i, p_{i+1})    # 按表中所列点序
  ```

> **注（✅ 论文原文）**：表中特征名称中的左右相对图本身而言。

**"水平夹角余弦值"的计算实现**

线段 [a-b] 与水平方向的夹角的余弦值，即该线段在水平轴上的投影占比：

```
cos_θ = (x_b - x_a) / sqrt((x_b - x_a)² + (y_b - y_a)²)
```

论文进一步说明：**"角度特征值通过计算角度的绝对值获得"**（第 2 页，1.2 节），即最终取：

```
feature = |cos_θ|
```

取绝对值的目的：消除左右方向的符号差异，使特征只反映"倾斜程度"而不含方向，从而更好表示面部特征的细微差别。

**分母为 0 的边界情况（⚠️ 论文未讨论）**：当线段完全垂直（Δx = 0）时余弦值为 0，数学上无异常；但当线段长度为 0（重合点）时会出现 0/0，实现时应加极小量 `eps = 1e-8` 防护。

### 步骤 3：特征归一化

**原理（✅ 论文给出，第 2 页 1.2 节）**

> "其中距离特征值通过两点间距离和脸部宽度（假设**点 0 到点 16 的距离**为脸部宽度）归一化获得，角度特征值通过计算角度的绝对值获得。特征值归一化有助于确保特征在分析中的一致性和准确性，从而更好地表示面部特征的细微差别。"

**实现参数**

| 参数 | 取值 | 来源 |
|---|---|---|
| 距离特征归一化基准 | `face_width = d(点0, 点16)` | ✅ 论文明确 |
| 归一化公式 | `f_norm = d(a,b) / face_width` | ✅ 论文明确 |
| 角度特征归一化方式 | 取绝对值 | ✅ 论文明确 |
| ⚠️ 注意 | 论文把 `d(点0,点16)` 称为"脸部宽度"（face width），本地 CSV 用 `_iod` 后缀命名 | ⚠️ 术语差异，注意别混淆 |

**⚠️ 重要提示**：`d(点0, 点16)` 在解剖学上是**下颌轮廓两端（左右脸颊最外点）的距离**，论文称其为"脸部宽度"。而通常文献中 IOD（Inter-Ocular Distance，瞳距/眼距）指的是两眼间的距离。本地 CSV 中所有距离特征都带 `_iod` 后缀，命名沿用了论文的 "IOD" 缩写但语义是"脸部宽度"。**复现时务必统一，不要用眼距做分母。**

**论文的质量核查结论（✅ 论文给出）**

- 距离和角度相关的特征值**均符合正态分布，未出现异常值**，可以作为机器学习算法中的样本特征值。
- 有 3 个特征集分别对应 DiGeorge 综合征、唐氏综合征、Williams 综合征（此处论文表述略含糊，实际指按类别分组后的特征分布直方图，见图 3、图 4）。

- Top 10 中，**距鼻尖相关的特征占 2 个**（第 1、3 名），**嘴唇角度特征占 3 个**（第 6、7、9 名），**鼻梁长度第 2 名**。
- 这与 3 种疾病的典型表型高度吻合：唐氏综合征的鼻梁扁平、眼距增宽；Williams 综合征的鼻尖宽大、嘴唇厚。
- 论文原文举例指出：`nosetip2lefteye`（鼻尖到左眼角内侧的距离）、`nose_bridge_length`（鼻梁长度）、`nosetip2righteye`（鼻尖到右眼角内侧的距离）等特征表现出较高的重要性。
- **特征重要性分数总和仅约 0.32**（10 个特征之和粗略估算约 0.32），说明单个几何特征的判别力有限，这也解释了为什么必须与深度特征融合。

### 步骤 5：Dlib 深度特征提取（128 维）

**原理（✅ 论文给出，第 4 页）**

> "在使用深度学习特征方面，选用 Dlib 的 128 维向量作为面部总体特征集，它是由一个基于 **ResNet** 的深度学习网络生成，经**过修改以适应面部识别任务**。Dlib 通过**增加全局平均池化层**，将卷积层的输出转换成 128 维的特征向量，这一向量就是面部的深度学习特征。比较两个面部图像时，可以通过比较它们的特征向量之间的**欧几里得距离**来确定相似度，如果**距离小于某个阈值**，则认为这两张面孔属于同一个人。"

**关键点**

- 网络骨干：**ResNet**（论文未给出具体层数，Dlib 官方为 ResNet-29 变体）
- 关键改动：增加**全局平均池化层（Global Average Pooling）**
- 输出维度：**128 维**
- 训练目标：面部识别（metric learning，使同一人向量距离小、不同人距离大）
- 相似度度量：欧几里得距离 + 阈值判定

**实现参数**

| 参数 | 取值 | 来源 |
|---|---|---|
| 深度特征维度 | **128** | ✅ 论文明确 |
| 骨干网络 | ResNet + 全局平均池化 | ✅ 论文明确 |
| 模型文件 | `dlib_face_recognition_resnet_model_v1.dat` | ⚠️ 论文未给出文件名，Dlib 官方标准模型 |
| 调用接口 | `dlib.face_recognition_model_v1(...).compute_face_descriptor(img, shape)` | ⚠️ 论文未给出 |
| 距离度量 | 欧几里得距离 | ✅ 论文明确 |
| 判定阈值 | 论文未给出具体数值 | ⚠️ Dlib 官方推荐 `0.6`（仅用于"同一人"判定，本文不直接使用） |
| 输入对齐 | 需先做关键点定位 + 仿射对齐 | ⚠️ 论文未明确，但 Dlib descriptor 内部依赖 68 点做对齐，**必须传入 landmark** |

**⚠️ 实现陷阱**：`compute_face_descriptor` 需要传入 shape（关键点），内部会做 5 点仿射对齐。如果只用检测框不做对齐，128 维向量的稳定性会显著下降。

**论文的说明（第 3 页 2.3 节）**：论文明确指出深度特征的优势是"在大量人脸图片经过深度学习模型提取"，但其对罕见病预测的短板是"**可解释性差**"。

### 步骤 6：特征融合（61 → 10 → +128 = 138 维）

**原理（✅ 论文给出）**

> "通过将几何特征与 Dlib 深度学习特征融合，特征维度从 128 维变成 138 维，测试表明这进一步提升了分类效果。"

**融合方式：直接拼接（concatenation）**

```
X_final = [ geom_top10 (10维) , dlib_embedding (128维) ]   → 138 维
```

**维度账目（✅ 论文给出）**

| 特征集 | 维度 | 来源 |
|---|---|---|
| 全部几何特征 | 61（35 距离 + 26 角度） | 步骤 2 |
| 筛选后几何特征 | **10** | 步骤 4 |
| Dlib 深度特征 | **128** | 步骤 5 |
| **融合特征** | **10 + 128 = 138** | 步骤 6 |

**⚠️ 工程注意事项**

- **尺度差异**：几何特征已归一化到 [0, 1] 量级，而 Dlib 128 维向量每个分量也是 ~[-1, 1] 但**未做 L2 归一化**。树模型（RF/XGBoost）对尺度不敏感，但 **SVM 和 MLP 对尺度敏感** —— 论文未提及是否做了标准化。
- **强烈建议**：对 SVM / MLP，在**训练折内部**拟合 `StandardScaler`（或对几何特征和深度特征分别做），再变换验证折。这可能是小样本下 SVM/MLP 表现好的关键之一。

### 步骤 8：评估指标与结果

**评估指标（✅ 论文给出）**

1. **精确率**（Precision）
2. **召回率**（Recall）
3. **F1 值**（F1-score）
4. **AUC 值**（Macro/Micro-averaged AUC，**采用 micro-averaging**）
5. **ROC 曲线**：**微平均方法**计算
6. **混淆矩阵**：用于获取上述指标
7. **准确率**（Accuracy，在 2.4 节分析中提及）

**表 4：不同机器学习方式下 3 种特征集的模型测试性能指标（✅ 论文给出）**

> 格式说明：**"几何特征 / 深度学习特征 / 融合方式"**
> 即每格三个数依次为：仅几何特征 / 仅深度特征 / 融合特征

| 建模方法 | 精确率 | 召回率 | F1 值 | AUC 平均值 |
|---|---|---|---|---|

|---|---|

**结论（✅ 论文给出）**

1. 融合几何特征和深度学习特征后，**绝大部分性能指标都比单独用深度学习特征有了进一步的提升**。
2. 对于多层感知器来说，**所有性能指标都是最佳的**。
3. 仅用几何特征建模已具备**初步分类预测功能**，但平均 AUC 值和正负类识别率**仍有提升空间**。原因：
   - 样本数量少；
   - 只提取了 10 个比较重要的几何特征，只能涵盖部分尺寸距离和角度特征，不能表示面部的其他特征。
4. Dlib 深度特征各项指标都比单纯用 10 个面部几何特征要高，但**可解释性差**。
5. 融合后特征维度从 128 维变成 138 维，进一步提升了分类效果。
6. 10 折交叉验证结果显示，性能提升**并非由于数据分割的偶然性**，模型在不同数据子集上的表现普遍改善，说明**泛化能力更强**；AUC 值提升也反映出模型**在定义决策边界方面的能力得到增强**。

**数据分析补充（✅ 论文第 4 页 2.4 节）**

> "首先，加入 10 个几何特征后，总体分类性能显著提升，AUC 值的提升意味着模型在区分正负类方面变得更准确，从而提升了预测的可靠性。"

## 六、论文自述的局限性（✅ 论文第 3 节）

1. **几何特征的局限性**：尽管几何特征在分类模型中表现出一定有效性，但**不足以全面捕捉罕见病的复杂面表型**。几何特征单独使用效果有限，与深度特征融合后才提升了模型性能，说明**这些几何特征仍然依赖于深度学习模型的有效性**。
2. **实际应用中的挑战**：方法可解释性较好，但罕见病的面部表型通常是**多维度和复杂的**，简单的几何特征可能无法充分描述这一复杂性。
3. **类别不均衡**：由于样本数量有限，模型**在某些罕见病的分类上表现出不均衡**，可能导致实际应用中的**误诊或漏诊**。
4. **模型泛化能力的限制**：交叉验证减少了数据集分割的随机性，但在**小样本**情况下，模型的泛化能力仍需**进一步验证**。

**未来工作方向（✅ 论文第 4 节）**

- 探索如何结合**更为丰富的深度学习特征与几何特征**
- 通过**数据增强技术**提升模型的稳健性
- 利用**合成数据**来扩展样本量
- 引入**更多样化的数据集**

## 十、一句话总结

> 本文用 **Dlib 提取 68 关键点 → 构造 61 个可解释几何特征（距离÷脸宽归一化 + 角度取绝对值）→ 随机森林筛出 Top 10 → 与 Dlib 的 128 维 ResNet 深度特征拼接成 138 维 → 在 109 张 NIH 罕见病面部数据上做 3 分类 × 4 模型 × 10 折交叉验证**，证明「几何 + 深度」融合特征在小样本场景下全面优于单一特征，最佳结果为 **MLP + 融合特征，AUC = 0.98**，并保留了优于纯深度学习模型的可解释性。
